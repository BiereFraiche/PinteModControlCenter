C. PC CONTROL CENTER DISTANT SUR LE LAN
---------------------------------------
Garder la cible RCON LAN actuelle. Ne pas remplacer son adresse par 127.0.0.1.

D. TEST IDENTITE SERVEUR
------------------------
1. Serveur > Actualiser.
2. Le nom public actuel doit apparaitre dans le champ de modification.
3. Modifier une lettre ou un code couleur ^0..^9.
4. Appliquer.
5. Verifier la confirmation locale et le nom observe.
6. Changer de map ou redemarrer ensuite pour verifier la restauration du nom.

Le bridge utilise live_steam_server_name comme autorite publique et sv_hostname
uniquement pour compatibilite. Aucun CFG n'est reecrit.

E. MOT DE PASSE JOUEUR
----------------------
Le bridge observe uniquement si net_password est actif, jamais sa valeur.
En loopback 127.0.0.1, SET reste disponible directement.
Depuis un autre PC du LAN prive :
1. garder l'adresse RCON 192.168.x.x actuelle ;
2. cocher "Autoriser le mot de passe via RCON LAN pour cette session" ;
3. saisir le nouveau mot de passe ;
4. confirmer l'avertissement.

L'opt-in LAN n'est jamais enregistre et disparait a la fermeture du Control Center.
Attention : RCON BOIII n'est pas chiffre ; la valeur transite donc sur le LAN pendant l'envoi.
Le Control Center ne lie pas le mot de passe au ViewModel, ne le journalise pas, ne le persiste
pas et ne le reaffiche jamais. CLEAR ne transporte aucune valeur sensible.

F. CHANGE MAP REEL
------------------
1. Choisir UNIQUEMENT une carte incluse dans l'allowlist lors de l'installation.
2. Confirmer le changement.
3. Verifier la console BOIII puis le chargement de la nouvelle carte.
4. Tester ensuite une carte officielle volontairement NON incluse : elle doit etre refusee.

Important : supported ne signifie pas installed.
La carte doit passer deux controles cote serveur :
- liste fermee des 14 cartes officielles ;
- allowlist locale explicite de ce serveur.

Les cartes custom sont refusees et l'auto-rotation n'est pas modifiee.
