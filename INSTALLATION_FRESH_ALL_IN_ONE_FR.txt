Integration Preview 4B1 Fix15 - 2026-08-28

RESULTAT FINAL
--------------
Apres compilation, deux formats autonomes sont disponibles :
  1. single-exe\PinteMod.ControlCenter.exe
  2. folder\ (dossier complet, egalement fourni en ZIP)

Choisir un format. Pour le format dossier, copier ou extraire tous les fichiers ensemble.

Ce meme EXE sert a :
- gerer Server1/Server2/Server3 et jusqu'a 8 profils ;
- analyser une installation BOIII existante ;
- installer le payload PinteMod actuel ;
- installer/mettre a jour le Bridge Control Center ;
- controler les serveurs via RCON ;
- lancer localement Worker v3 + RecordHub + Ban + GeoIP ;
- agir comme Agent de lancement distant sur le PC serveur ;
- lancer un serveur depuis un autre PC via un partage SMB/UNC apres pairing.

2. FRESH INSTALL BOIII / PINTEMOD
---------------------------------
Le serveur BOIII doit deja exister : le Manager ne telecharge pas BOIII ni les fichiers de maps.
Depuis le PC serveur OU via un chemin UNC accessible en ecriture :
- Ajouter le serveur dans PinteMod Manager.
- Renseigner sa racine contenant boiii.
- ANALYSER.
- Si PinteMod absent : INSTALLER PINTE MOD ACTUEL.
- Puis INSTALLER / METTRE A JOUR LE BRIDGE.
- Cocher seulement les cartes reellement installees pour Change Map.

Le deployeur est fail-closed :
- aucun script tiers n'est modifie ;
- un fichier first-party existant mais inconnu bloque l'ecriture ;
- aucun scriptdata, secret, log ou profil joueur n'est embarque.

3. CONFIGURER LE PC SERVEUR POUR LE LANCEMENT DISTANT
------------------------------------------------------
Cette etape est locale et necessaire une seule fois.
- Copier le meme EXE sur le PC serveur et le lancer dans la session Windows qui fait tourner les serveurs.
- Ajouter les profils locaux Server1/Server2/Server3 avec chemins locaux.
- Pour chaque profil : ANALYSER + ENREGISTRER.
- Ouvrir le Control Center de chaque profil et enregistrer le secret RCON local via DPAPI.
- Revenir au Manager.
- Cliquer ACTIVER / MAJ AGENT SUR CE PC.

Le Manager :
- installe une copie du meme EXE dans %LocalAppData%\PinteMod\ControlCenter\remote-agent ;
- l'enregistre au demarrage de la session Windows ;
- demarre l'Agent immediatement ;
- enregistre tous les profils BOIII locaux ;
- genere un pairing de 15 minutes par serveur ;
- reutilise le secret RCON DPAPI local pour preparer le secret DPAPI attendu par Worker v3 quand il est disponible.

4. CONFIGURER LE PORTABLE / PC DISTANT
--------------------------------------
- Le PC distant doit rejoindre le reseau prive du serveur, directement ou via un VPN administre.
- Ne jamais exposer SMB, RCON ou RDP directement sur Internet.
- Copier le meme EXE ou le dossier complet de la meme version sur le portable/VM.
- Ajouter Server1/2/3 avec leurs chemins UNC, par exemple :
    \\PC-SERVEUR\Partage\Server3
- Renseigner l'adresse RCON LAN du PC serveur et le port correct.
- ANALYSER + ENREGISTRER.
- Dans LANCEMENT DISTANT SMB : PAIRER CE PROFIL DISTANT.
- ACTUALISER L'AGENT.
- Attendu : Agent ONLINE.
- Enregistrer aussi le secret RCON dans le Control Center du portable via son stockage DPAPI local.

5. LANCER DEPUIS LE PORTABLE
----------------------------
Selectionner un serveur puis LANCER & OUVRIR.
Le portable n'execute jamais directement un BAT UNC.
Il depose uniquement une requete launch signee.
L'Agent du PC serveur :
- verifie expiration + nonce + HMAC ;
- retrouve le serveur dans sa configuration locale ;
- lance PinteMod via Worker v3 si PinteMod est detecte ;
- garde RecordHub configure avec tous les profils PinteMod locaux ;
- laisse Worker v3 gerer Supervisor, Ban, GeoIP et la reconciliation BOIII ;
- renvoie une reponse signee au portable.

LANCER TOUS DISPONIBLES fonctionne aussi :
- profils locaux : lancement groupe Worker v3 ;
- profils UNC pairés : requetes Agent successives.

6. AJOUTER UN SERVER4 PLUS TARD
-------------------------------
Sur le PC serveur :
- ajouter Server4 avec sa racine locale ;
- analyser/enregistrer ;
- cliquer de nouveau ACTIVER / MAJ AGENT SUR CE PC.
Cela regenere un pairing 15 minutes et met a jour l'Agent.

Sur le portable :
- ajouter le chemin UNC Server4 ;
- analyser/enregistrer ;
- pairer ;
- utiliser normalement.

7. SUPPRIMER UN PROFIL
----------------------
RETIRER CE PROFIL ne supprime jamais le serveur, les GSC, les records ou le secret RCON du serveur.
Il retire uniquement le profil du Manager du PC courant.
Pour retirer un serveur de l'Agent, retirez son profil local sur le PC serveur puis relancez ACTIVER / MAJ AGENT SUR CE PC.

8. SECURITE SMB
---------------
Le dossier partage doit etre accessible uniquement aux comptes Windows autorises.
Le pairing.json contient temporairement une cle pendant 15 minutes ; apres pairing le portable le supprime et stocke la cle via DPAPI.
Les demandes de lancement ulterieures ne contiennent pas cette cle.
Aucun chemin executable, PowerShell, RCON brut ou argument arbitraire n'est accepte par le protocole Agent v1.

9. GEOIP
--------
Le payload inclut le GeoIP Stats Fix1 :
- countries.json > 1 Mo est traite comme anormal ;
- maximum 300 pays ;
- noms/codes bornes ;
- tmp unique par PID ;
- ecriture atomique.
Le Manager peut analyser et reparer les stats pays sans toucher ranks/records/langues/bans/profils.

10. LIMITES DE CETTE PREVIEW
----------------------------
- L'Agent est un processus utilisateur lance a l'ouverture de session Windows, pas un service SYSTEM.
- Il faut donc qu'une session du compte serveur ait ete ouverte apres un redemarrage Windows.
- BOIII sans PinteMod est detecte et peut utiliser les fonctions natives deja prouvees ; le Generic BOIII Bridge complet/capability engine reste la prochaine phase.
- Les maps BOIII elles-memes ne sont jamais embarquees dans l'EXE.
