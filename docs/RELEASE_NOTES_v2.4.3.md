# PinteMod Control Center v2.4.3

## Premier lancement et diagnostic plus simples

Le bouton **Lancer tous** adopte le même premier-lancement que **Démarrer** : sans secret RCON, le serveur local démarre par son lanceur enregistré. Les serveurs déjà configurés restent gérés par le Worker PinteMod.

Le diagnostic santé présente maintenant les données locales fraîches de PinteMod quand BOIII ne répond pas sur RCON, tout en conservant le RCON comme non confirmé pour les actions d’administration.
