# PinteMod Control Center v2.4.5-rc7

Candidate de recette finale. Elle remplace rc6 pour le test terrain décrit dans [la recette finale](RECETTE_FINALE_FR.md).

- Chaque profil enregistré est désormais chargé séparément au démarrage.
- Un profil ancien ou une source locale indisponible ne peut plus fermer le tableau de bord complet.
- Si aucun profil ne peut être chargé, un onglet de récupération non persistant donne accès au Gestionnaire sans modifier les profils, les chemins locaux, les réglages RCON ou les secrets DPAPI.

Ce n'est pas la version stable publique. Ne publiez ni le fichier privé de secrets ni son mot de passe.
