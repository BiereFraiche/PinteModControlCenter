PINTE MOD / CONTROL CENTER - SERVER BRIDGE PREVIEW v0.3.1
=======================================================

TESTER D'ABORD SUR SERVER3 UNIQUEMENT.

1. Arreter Server3.
2. Double-cliquer INSTALL_CONTROL_CENTER_SERVER_PREVIEW.bat.
3. Donner le dossier racine de Server3 (celui qui contient boiii).
4. Declarer uniquement les cartes officielles REELLEMENT installees et autorisees.
5. Redemarrer Server3.
6. Verifier dans la console :
   [PinteMod] Control Center Contracts Preview v0.3.1 loaded

Le BAT ajoute uniquement :
- boiii/custom_scripts/ezz_admin_control_center_contracts.gsc
- boiii/scriptdata/pintemod/config/control_center_map_allowlist.json

Le GSC produit ensuite automatiquement :
- boiii/scriptdata/pintemod/diagnostics/control_center_capabilities.json
- boiii/scriptdata/pintemod/runtime/server_identity.json
- boiii/scriptdata/pintemod/remote/action_feedback.latest.json apres une mutation

HOSTNAME
--------
- source publique BOIII : live_steam_server_name ;
- sv_hostname est mis a jour en parallele pour compatibilite ;
- le nom valide peut etre persiste dans
  pintemod/config/control_center_identity.json ;
- aucun server_zm.cfg n'est lu ou reecrit.

MOT DE PASSE JOUEUR
-------------------
- autorite BOIII : net_password ;
- seule sa presence (true/false) est publiee ;
- la valeur n'est jamais ecrite dans les JSON ;
- SET reste bloque par le Control Center si le RCON n'est pas loopback.
  Depuis un PC distant LAN, garder l'adresse LAN actuelle : c'est normal que SET soit grise.

CHANGE MAP
----------
- ezzccmap accepte uniquement les 14 codes officiels fermes ;
- la carte doit EN PLUS etre dans control_center_map_allowlist.json ;
- supported ne signifie pas installed ;
- aucune carte custom ;
- aucune commande console libre ;
- l'auto-rotation PinteMod n'est pas modifiee.

Cette Preview n'est pas une stable avant validation terrain.


BOSS / EVENTS - POINT 5
-----------------------
Le bridge v0.3.1 publie des alias boss fermes uniquement si le module
PinteMod Events est charge et uniquement pour la carte active :
- zm_zod : margwa
- zm_castle : panzer
- zm_island : thrasher
- zm_stalingrad : panzer
- zm_genesis : margwa, shadow_margwa, fire_margwa, panzer
- zm_moon : astronaut
- zm_tomb : panzer

La commande Control Center ezzccboss revalide : request_id, BOIII_XUID,
carte active, alias, module Events, limite de boss et position visee.
Elle produit ensuite un feedback local applique/refuse/echec.
Aucun nom de spawner ni fonction GSC ne vient de l'interface.
Les autres evenements restent non exposes tant qu'ils ne sont pas valides
map par map.

CORRECTIF INSTALLATEUR UNC
-------------------------
Le BAT de ce paquet est compatible avec un lancement depuis un partage UNC.
Il utilise PUSHd pour mapper temporairement le dossier du paquet et la racine
serveur sur des lettres de lecteur. Le BAT est en ASCII sans BOM + CRLF afin
d'eviter le probleme "´╗┐@echo off" de CMD.EXE.
Le payload GSC reste strictement v0.3.1.
