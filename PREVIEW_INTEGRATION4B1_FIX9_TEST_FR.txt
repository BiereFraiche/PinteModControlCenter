PinteMod Control Center — Integration Preview 4B1 Fix9
TEST CIBLE — CATALOGUE AGENT + ETAT BOIII DISTANT
======================================================

BUT
---
Valider que les serveurs BOIII locaux enregistrés sur le PC serveur peuvent être
découverts depuis le portable via un Agent déjà appairé, sans recopier de chemin
local Windows, de secret ou de commande arbitraire.

1. BUILD WINDOWS
----------------
- Extraire l'archive dans un nouveau dossier.
- Double-cliquer BUILD_PREVIEW.bat.
- Exiger : 0 avertissement, 0 erreur, tous les tests Debug + Release, puis Publish.

2. PC SERVEUR — FIX9 D'ABORD
----------------------------
- Lancer le nouvel EXE Fix9 sur le PC qui héberge physiquement Server4.
- Ouvrir le Manager et enregistrer/analyser Server4.
- Si l'Agent PinteMod est déjà installé sur ce PC, la Fix9 actualise automatiquement
  ses enregistrements locaux lorsque le catalogue a changé.
- Si aucun Agent n'a jamais été installé sur ce PC, utiliser une fois :
  ACTIVER / MAJ AGENT SUR CE PC.
- Laisser l'Agent tourner quelques secondes.

Résultat attendu local :
- Server4 BOIII natif peut afficher EN LIGNE / ARRETE d'après le processus BOIII local.
- La source doit être PROCESSUS BOIII LOCAL, pas HEARTBEAT PINTE MOD LOCAL.
- Carte/manche/joueurs restent indisponibles si aucune télémétrie structurée n'existe.

3. PORTABLE — DECOUVERTE DU CATALOGUE
-------------------------------------
- Mettre le portable sur la même Fix9.
- Il doit déjà posséder au moins un profil UNC appairé vers ce même PC serveur
  (exemple : Server3 DE).
- Ouvrir le Manager ou cliquer ACTUALISER sur ce profil appairé.

Résultat attendu :
- Server4 apparaît automatiquement dans MES SERVEURS si sa racine UNC peut être
  prouvée comme sœur du serveur déjà connu.
- Aucun chemin local du PC serveur n'est copié : seule une racine UNC réellement
  accessible et contenant boiii est acceptée.
- Le nouveau profil Server4 peut demander un pairing propre avant les commandes.

4. PAIRING SERVER4
------------------
- Le pairing du nouveau profil reste volontairement explicite.
- Cliquer PAIRER CE PROFIL DISTANT pendant la fenêtre de pairing disponible.
- Si le pairing a expiré, sur le PC serveur cliquer ACTIVER / MAJ AGENT SUR CE PC,
  puis refaire le pairing dans les 15 minutes.

Résultat attendu après pairing + Agent ONLINE + même version :
- Dashboard portable : état EN LIGNE / ARRETE issu du runtime Agent SMB signé.
- Source : PROCESSUS BOIII DISTANT · AGENT SMB.
- Carte/manche/joueurs restent vides pour BOIII natif sans source fiable.
- DEMARRER/ARRETER ne s'activent que si le transport Agent est réellement prêt.

5. FAIL-CLOSED A CONSERVER
--------------------------
- Aucun profil inventé si la racine UNC sœur n'existe pas.
- Aucun import depuis un catalogue non signé, périmé ou altéré.
- Aucun secret Agent transféré dans le catalogue.
- Aucun chemin local Windows publié dans le catalogue.
- Aucun GSC tiers modifié ou commande tierce devinée.
- Aucun profil local supprimé automatiquement si un serveur disparaît du catalogue.
