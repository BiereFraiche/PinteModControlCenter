TEST HUMAIN - ONBOARDING PREVIEW 4A2
==================================

1. BUILD
Double-cliquer BUILD_PREVIEW.bat.
Attendu : Debug OK, tests Debug OK, Release OK, tests Release OK, SINGLE EXE OK.
EXE : app\artifacts\onboarding-preview4a2-win-x64\PinteMod.ControlCenter.exe

2. MISE A JOUR AGENT
La 3M sait deja s'auto-mettre a jour.
Depuis le Control Center principal 4A, utilisez METTRE A JOUR pour pousser la 4A a l'Agent distant.
Verifier ensuite que l'Agent indique 2.4.0-preview-onboarding.4a2.

3. MODE SIMPLE
Au lancement, verifier :
- deux choix visibles : CONFIGURER UN SERVEUR SUR CE PC / AJOUTER UN SERVEUR DU RESEAU ;
- pas de RCON/SMB/Worker affiche en premier plan ;
- bouton MODE AVANCE disponible ;
- fermer/rouvrir apres changement de mode et verifier que le choix est memorise.

4. SERVEUR PINTEMOD EXISTANT
Choisir Server3 local.
Attendu : "Serveur pret avec PinteMod", matrice de fonctions, UTILISER CE SERVEUR.
Ouvrir Control Center et verifier absence de regression lancement/dashboard/Agent.

5. PROFIL RESEAU
Ajouter Server3 par partage UNC.
Si le chemin commence par \\IP\..., l'adresse locale doit etre pre-remplie.
Sinon saisir l'IP locale dans le champ simple affiche.
Pairing/lancement distant doivent rester fonctionnels.

6. BOIII VIDE - A FAIRE UNIQUEMENT SUR COPIE DE TEST
Creer/utiliser une racine BOIII de test sans PinteMod et sans GSC tiers.
Attendu : "Serveur BOIII detecte" puis INSTALLER ET PREPARER PINTE MOD.
Le serveur doit etre arrete.
Verifier installation PinteMod + Bridge et aucune ecriture dans un fichier existant different.

7. GSC TIERS - COPIE DE TEST
Placer un GSC tiers dans boiii\custom_scripts sans PinteMod.
Attendu : "Scripts personnalises detectes".
Le bouton simple ne doit PAS proposer l'installation automatique de PinteMod.
Les fonctions non prouvees sont indiquees indisponibles et les pages Joueurs/Records sont grisees dans le Control Center de ce profil reel.
Aucun GSC tiers ne doit etre modifie.

8. MODE AVANCE
Verifier que les panneaux repliables donnent acces aux details RCON, lanceur, integration, Agent et maintenance.
