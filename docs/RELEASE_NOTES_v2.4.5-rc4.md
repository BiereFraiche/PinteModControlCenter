Candidate de recette finale. Elle remplace la rc3 pour le test terrain unique décrit dans [la recette finale](RECETTE_FINALE_FR.md).

Ce n'est pas la version stable publique. Ne publiez ni le fichier privé de secrets ni son mot de passe.
