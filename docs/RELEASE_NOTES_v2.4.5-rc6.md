# PinteMod Control Center v2.4.5-rc6

Candidate de recette finale. Elle remplace rc5 pour le test terrain décrit dans [la recette finale](RECETTE_FINALE_FR.md).

- Le gestionnaire de serveurs reste accessible si l’actualisation automatique d’un Agent local, d’un catalogue réseau ou de l’analyse initiale d’un serveur échoue.
- L’échec est signalé dans le gestionnaire sans afficher de chemin privé, de réglage RCON ou de secret.
- Les actions **Actualiser**, **Analyser** et la réparation d’Agent restent disponibles pour corriger la source concernée.

Ce n'est pas la version stable publique. Ne publiez ni le fichier privé de secrets ni son mot de passe.
