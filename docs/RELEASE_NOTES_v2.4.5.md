# PinteMod Control Center v2.4.5

## Stable release

Le parcours complet sur serveur BOIII vierge est validé : ajout depuis le Gestionnaire, installation PinteMod, création ou remplacement confirmé du RCON, démarrage BOIII et contrôle de santé PinteMod.

- Le remplacement RCON répare les fichiers secrets PinteMod/GeoIP manquants sans afficher d’ancienne valeur.
- L’Agent distant est une fonction explicite ; il peut être désactivé intégralement, y compris sa relance Windows et ses files locales.
- Le Control Center se ferme de façon bornée et ne doit plus rester dans le Gestionnaire des tâches après la fermeture de sa fenêtre.
- Les résultats RCON sont affichés directement dans Paramètres, sans divulguer de secret.
