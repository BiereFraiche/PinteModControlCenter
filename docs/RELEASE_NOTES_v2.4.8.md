# PinteMod Control Center v2.4.8

## One-click Control Center updates

- **Vérifier GitHub** now displays **Mettre à jour** when a newer public version is available.
- The Control Center downloads only the official GitHub EXE, checks its published SHA-256 digest, then closes, replaces itself and restarts.
- If the download, size or checksum is unexpected, the current application is left unchanged.

## How to use it

1. Open the manager window.
2. Click **Vérifier GitHub**.
3. When a newer version is shown, click **Mettre à jour** once.

The application restarts automatically when the update is ready.
