# Changelog

## v2.4.5 — stable

The final public version focuses on a simple and reliable server setup:

- guided installation of PinteMod on a compatible BOIII/Ezz server folder;
- first RCON setup and safe confirmed replacement;
- server start from the Control Center and PinteMod health check;
- clearer multi-server Manager, local health display, logs, player information and records;
- optional Remote Agent kept disabled by default and fully removable from the Manager;
- French and English interface selection;
- standalone Windows EXE and portable-folder packages, with SHA-256 and offline self-test.

Validation completed: Debug and Release builds with no warnings or errors, and 629 automated tests passing in both configurations.

For the full user guide, return to the [README](README.md) or the [French README](README_FR.md).
