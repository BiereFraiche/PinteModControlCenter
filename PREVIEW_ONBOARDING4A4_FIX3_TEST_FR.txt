PinteMod Control Center - Onboarding Preview 4A4 Fix3
======================================================

Objet
-----
Corriger le bouton ARRÊTER CE SERVEUR qui pouvait renvoyer une erreur
PowerShell/CLIXML "Le terminateur ' est manquant dans la chaîne".

Correction
----------
- suppression de PowerShell -EncodedCommand pour l'arrêt ;
- génération d'un script temporaire first-party UTF-8 BOM ;
- appel via powershell.exe -File avec ArgumentList ;
- paramètres transmis uniquement par variables d'environnement ;
- script d'arrêt simplifié pour PowerShell 5.1 ;
- sortie d'erreur CLIXML neutralisée avant affichage ;
- le fichier temporaire est supprimé après exécution.

Test humain
-----------
1. BUILD_PREVIEW.bat.
2. Mettre à jour le PC serveur/Agent avec le nouvel EXE.
3. Lancer un seul serveur depuis le Control Center.
4. Attendre que ARRÊTER CE SERVEUR soit actif.
5. Cliquer ARRÊTER CE SERVEUR puis confirmer.
6. Vérifier que BOIII se ferme sur la machine serveur.
7. Vérifier que le Dashboard repasse OFFLINE automatiquement.
8. Vérifier qu'aucun autre serveur n'est arrêté.
9. Vérifier qu'aucun texte CLIXML n'est affiché.
